# Ponto PJ

Controle de horas para quem trabalha como PJ: cronômetro, centros de custo, valor por hora e
relatório em PDF, com os registros numa planilha da sua própria conta Google.

- **Site:** https://fabioisschmitt.github.io/pontopj-site/
- **Baixar para Android:** [PontoPJ.apk](https://github.com/FabioIsSchmitt/pontopj-site/releases/latest/download/PontoPJ.apk) (versão mais recente)
- **Política de privacidade:** https://fabioisschmitt.github.io/pontopj-site/privacidade.html
- **Contato:** pontopj.app@gmail.com

Este repositório guarda só o site (página inicial e política de privacidade) e as versões do app
para download, em [Releases](https://github.com/FabioIsSchmitt/pontopj-site/releases).
